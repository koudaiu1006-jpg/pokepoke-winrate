# ポケポケ 勝率カウンター

ポケモンカードゲーム Pocket（ポケポケ）のデッキ別 戦績・勝率カウンター。
対戦が終わったら「勝ち／負け／引き分け」を1タップするだけで、戦績と勝率を自動で計算します。

- 公開URL: https://koudaiu1006-jpg.github.io/pokepoke-winrate/
- 構成: `index.html`（単一ファイル・外部ライブラリなし）＋ `icon-180.png`（ホーム画面アイコン）

## 使い方

1. 上の入力欄にデッキ名を入れて「＋ 追加」。
2. 対戦後に「勝ち」「負け」「引き分け」を押すと ＋1 されます。
3. 勝率は `勝ち ÷ 総戦数 × 100`（小数第1位）。0戦のときは `--%`。
4. 押し間違えたら右上の「↩ 1つ戻す」で直前の1件を取り消し（リセットの取り消しも可）。
5. 「名前変更」「リセット」「削除」は各デッキの下。リセット・削除は確認ダイアログが出ます。
6. 画面上部の「全デッキ合計」で全デッキの通算戦績と通算勝率を確認できます。

## データの保存

戦績は端末のブラウザ内 `localStorage`（キー `pokepoke-winrate-v1`）にのみ保存され、サーバーには送信しません。
リポジトリに個人データは含まれません。ブラウザのサイトデータを消すと戦績も消えます。

## ホーム画面に追加

- iPhone（Safari）: 共有ボタン → 「ホーム画面に追加」。アプリ名は「ポケポケ勝率」。
- Android（Chrome）: メニュー → 「ホーム画面に追加」。

## 更新方法

`index.html` を編集して `main` に push すると GitHub Pages が自動で再ビルドします。
